# 销售分析与展示

只在任务涉及本项目销售数据或多步销售展示时使用。先读取 `references/data-contract.md` 获取数据字段和图表返回格式。

1. 明确用户目标、地区、年份和指标。保留用户要求的逐项询问顺序；无法从当前任务得知的必要参数用 request_clarification 询问，不能从无关任务猜测。
2. 用 query_sql 查询项目注册的 sales 数据源。利润为 revenue-cost；同比以去年绝对值为分母，去年为零时说明不可计算。组合计算可用 run_python 处理 data_ref。
3. 用户要求调整展示时，先 observe_page 读取实际动作和状态，再调用 execute_page_action。选择目标年份、地区、指标或视图，每一步等待回执并用返回版本继续。动作不存在时说明，不能假装点击。
4. 如需根据结果找出最佳地区，应先完成比较，再切换到选出的地区；不得预先猜测地区。纯分析需求无需修改页面。
5. 页面被其他操作改变时重新 observe_page，判断是否仍适合继续原流程。不要把旧筛选条件强加给用户的新视图。
6. deliver_result 返回简短口头结论、完整说明和约定的数据结构。不要在摘要里说“已受理”或再次要求等待。

该 Skill 描述工作方式，不提供新的数据库或页面权限。
