# 小云 1.0-alpha：冻结要求与验收清单

确认日期：2026-09-11（Asia/Shanghai）。本文件记录本轮讨论的最终决定；勾选必须附实际验证依据。发行版本采用 SemVer `1.0.0-alpha.1`，展示名称为 **1.0-alpha**。通过本轮检查也不自动称为稳定版 1.0。

## R1 通用助手与任务分工

- [x] Qwen 保留原生实时语音输入、输出、语义轮次检测和工具调用。**不增加独立 TTS，不改成文字转语音链路，不以字幕句号切断普通回应。**
- [x] Qwen 负责自然对话、当前日期、已有结果解释、明确的简单页面动作，以及后台任务的创建、补充、取消与交付控制。
- [x] 联网获取事实、计算、业务知识、多步规划及复杂页面操作交给独立 Pi Agent。已注册的完整直达业务函数仍可直接调用，计算由代码执行。
- [x] 通用系统提示和工具说明采用目标、参数、任务状态等通用规则；不固定城市、天气或销售为助手能力边界。具体业务流程放项目说明和 Skill，具体话术案例放测试。
- [x] 项目说明及 Skill 能力简介提供给 Qwen；Skill 正文仅由 Pi 按需读取。日期与星期继续从服务器时钟按 TIME_ZONE 动态注入，默认 Asia/Shanghai。

## R2 按项目配置业务 Skill

- [x] 项目可注册本地 Skill 目录（SKILL.md 与参考资料），包含名称、用途、业务口径、流程、工具使用及交付约定。
- [x] Pi 先读取能力目录，按需加载 Skill 正文和该 Skill 内的参考资料；澄清恢复保留已读取的知识。
- [x] Skill 提供操作知识，执行能力仍来自项目注册的数据源、业务工具和当前网页动作。不会因读取 Skill 自动获得任意文件、进程或子代理能力。
- [x] 提供可运行的示例 Skill，以及其他 Agent 在新网页项目中配置 Skill 的完整说明。

## R3 Pi 多步页面操作

- [x] Pi 能读取当前网页上下文与已注册动作描述，按步骤调用 SDK 中的原业务函数，并等待实际执行结果后决定下一步。
- [x] 浏览器函数留在宿主，后台不执行函数源码；动作按项目、连接和任务关联。
- [x] 同一页面的动作串行执行，调用时校验当前上下文版本。页面已改变时返回明确状态供 Pi 重新观察，不静默覆盖新视图。
- [x] 取消任务时未执行动作不再开始；已完成动作不重复执行。页面断开或动作失败向对应任务反馈，后台不能虚构成功。

## R4 并行任务与持续对话

- [x] 每个复杂任务有独立 Pi 上下文，默认最多三个并行，其他排队；启动立即返回编号，Qwen 不等待任务完成，用户可继续聊天和追加任务。
- [x] Pi 交付可直接朗读的简短结论、完整 Markdown/来源和结构化数据；Qwen 朗读摘要，不再二次总结整个报告。
- [x] 任务完成即保存、更新结果卡和小云任务记忆；“结果完成”和“结果已播”分开记录，避免完成后又说正在受理。
- [x] 补参只恢复待澄清任务；基于已完成任务改变条件新建任务；重播/摘读已有结果不重新执行。普通聊天及新任务不能误填上一任务参数。

## R5 原生语音的统一交付

- [x] Qwen 的一次普通原生回应是完整播放单元。后台结果到达只排队，必须等该回应的音频在浏览器实际排空后才接入，不能以模型生成结束代替。
- [x] 正式结果摘要作为完整交付组依次播完；其他结果不抢话。结果按完成顺序，同批完成按提出顺序，无额外凑批等待窗口。
- [x] 用户插话优先，立即停声；后台任务继续。被打断结果保留，明确不用播时跳过；迟到音频/回执不能影响新播报。
- [x] 沿用已有等待语单句机制；正在播放的句子不被任务完成截断。用户正在聊天时不插入重复进度提示；已过时的等待语不在聊天结束后补播。
- [x] 任务完成或安静不结束会话。点击立即关闭；明确语音告别播完后退出，插话可取消退出。退出后任务完成只更新结果卡。

## R6 保留组件体验与迁移接口

- [x] 保留角色动作、玻璃工具栏、鼠标跟随、拖动、系统减少动画仍有动效；本轮不重做展示大屏视觉。
- [x] 保留当前字幕、紧凑进度、最多三张普通结果卡、固定卡、阅读保护、详情折叠与自动退场。
- [x] 保留公开 SDK 接入方式和生命周期、结果/交付操作及 onEvent；必要协议变更同步更新 SDK、后台与示例。
- [x] 组件私有库不包含销售展示页、真实密钥、运行数据库或录音。继续保留来源说明，一键启动与本机后台可用。

## R7 验证与发行

- [x] 验证通用任务分流：非天气业务、补参、新条件任务、重播、普通聊天、退出；使用真实 Qwen 与可控工具回执，区分真实业务执行与路由夹具。
- [x] 验证 Skill 加载、引用边界、澄清恢复，以及真实 Pi 按 Skill 调用数据/页面工具完成任务。
- [x] 验证多步页面动作执行结果、动作串行、上下文变更、取消与错误反馈。
- [x] 用 Edge/Chrome 实际 AudioWorklet 验证：完整多句原生聊天尚未播完时任务完成、多个结果先后完成、用户插话，以及迟到事件。不得用估算时长代替播放回执。
- [x] 完成类型检查、构建和少量必要行为测试，不加哈希测试、机械 DOM 快照或覆盖率目标。
- [x] 更新 AGENTS.md、Skill/接入说明、测试大屏用例、独立接入示例和实际验收报告；生成安装包及私有 GitHub `v1.0.0-alpha.1` 预发行版本。
- [x] 重启本机展示后台，验证健康检查和启动器；记录实测范围及仍需实体麦克风/扬声器体验的项目。

## 实施顺序

保存检查点 → 通用提示与 Skill → Pi 页面动作桥接 → 异步播报与会话回归 → 测试页/文档 → 构建、真实模型与浏览器验证 → 同步私有库、预发行包、本机更新。

## alpha.2 用户反馈修复

- [x] 完整大屏初始化期间，不允许旧动作配置把页面版本退回旧值；页面冲突回执提供新快照。
- [x] 原生语音输入后的等待语只念指定短句，不复述问题或任务标题；等待缓存核对实际字幕。
- [x] 取消默认 16 轮执行上限，只有显式设置 AGENT_MAX_TURNS 正整数才限制执行轮数。
- [x] 同一长需求经浏览器收音、真实 Qwen/Pi、实际大屏复测，核对比较表、占比、页面状态和实际播放结束。

依据见 [alpha.2 修复记录](VALIDATION-1.0-alpha.2.md)。这次发现说明初次已检查的功能仍有未覆盖的组合场景，以上补充不替代实体麦克风体验。

## alpha.3 告别补充

- [x] 明确退出指令与当轮告别声音绑定，即使模型只口头道别而未调用工具，也在实际播放结束后退出。
- [x] 转写晚到不重复告别，用户插话可撤销退出，旧话轮不能关闭新会话。

依据见 [alpha.3 告别修复记录](VALIDATION-1.0-alpha.3.md)。

## alpha.4 连续对话补充

- [x] 任务结果和澄清播报后立即恢复普通会话工具，不等下一次语音开始；保持同轮受理去重。
- [x] 连续单项页面调整保留其他设置，实际调用动作再确认，不主动换算数据。
- [x] 同一会话经真实模型完成华东利润 → 华北 → 华南 → 告别，核对动作回执和实际页面。

依据见 [alpha.4 连续对话修复记录](VALIDATION-1.0-alpha.4.md)。

## alpha.5 前端展示调整

- [x] 左上方唯一说话气泡，只显示当前语音字幕，从弧形尾巴处展开；资料卡无尾巴。
- [x] 普通字幕和未固定资料默认播放交付后 10 秒退场，保留追问、固定与阅读规则。
- [x] 删除重复“正在说话”提示；新结果通知有独立位置，不盖住字幕或资料内容。
- [x] Edge/Chrome 用实际 AudioWorklet 验证显示归属、插话、计时、固定、遮挡与拖动；后端业务逻辑保持。

依据见 [alpha.5 字幕与资料卡记录](VALIDATION-1.0-alpha.5.md)。
