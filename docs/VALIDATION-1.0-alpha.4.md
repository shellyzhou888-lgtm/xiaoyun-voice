# 小云 1.0-alpha.4 连续对话修复

日期：2026-09-11。版本：1.0.0-alpha.4。

## 原因与修改

用户先说“帮我切换到华东地区的利润”，页面执行成功；随后说“我还想看看华北地区的”，Qwen 正确理解要继续看利润，并口头承诺切换，但没有产生工具调用。旧日志中第二轮没有页面请求或新任务，不是数据库或页面函数仍在运行。

代码中“本轮任务已受理”的保护会持续清空会话工具，直到下一次云端 speech_started 才恢复。实时语音推理可能已经使用了此前的会话配置。追问播完后也存在同类风险。新增协议夹具在修改前稳定失败：任务播报后，下一轮输入尚未开始时，页面工具仍为空。

现在任务去重继续由受理编号处理，播报/追问的禁用工具配置只用于对应响应；生成结束便恢复普通对话的工具与提示，插话时也立即恢复。当前声音仍按原有播放回执交付，不增加模型调用或 TTS。配置恢复遵循官方 [session.update 工具配置接口](https://platform.qianwenai.com/docs/developer-guides/speech/qwen-audio-realtime#function-calling)，恢复时机由本项目生命周期负责。

单个页面设置的连续调整沿用其他设置，通过页面工具直接执行；重新分析或查询不同条件才交给 Pi。动作确认只说明已改变的设置，不主动换算数值。第一次复测发现 Qwen 将华北利润单位换算错误，因此补充了该规则；最终复测确认语没有再附带未经要求的数值分析。没有添加地区关键词规则。

日志增加已发送/已确认配置的工具名称列表，不记录系统提示全文、密钥、音频或模型思考。

## 实际验证

- 类型检查、构建以及 46 项行为测试通过。新增验证在结果播报和澄清问题之后、下一次 speech_started 之前，工具已经恢复；保留同轮去重、多任务和澄清恢复检查。
- Edge 完整销售大屏，合成录音经过浏览器麦克风流、实际 AudioWorklet、真实 Qwen 和 Pi：连续说华东利润、华北、华南，最后告别。只建立一次会话；华北和华南各执行一次 set_region，保持 2026 年和 profit，没有新增后台分析任务。
- 每一轮云端讲话开始之前，已确认的配置均包含页面动作和后台任务工具。每轮声音实际排空后才进入下一轮。最后告别恢复“唤醒小云”按钮。
- 最终两条确认语分别为“已切换到华北地区，当前显示2026年华北利润数据。”和“已切换回华南地区，当前显示2026年华南利润数据。”
- Edge 可控协议 + 实际 AudioWorklet 回归通过：整段聊天播放结束后交接并行结果、用户插话、迟到事件、等待句交接、重播、页面版本保护与阅读保护。

复测命令：完整工作区 `npx tsx scripts/verify-continuous-voice.ts`。读取已有 Key，使用隔离任务数据库；不需要真人发声。报告见 `docs/evidence/validation-1.0-alpha.4.json`。

本次没有重做 Chrome 或实体麦克风声学验收。报告中的 cloudEndToActionRequestMs 是云端语音结束通知到浏览器收到动作请求的间隔，不能当成真实句末到屏幕变化的总延迟。SDK 与后台同步升级并刷新页面；保留此前标签。
