# 小云 1.0-alpha.3 告别修复

日期：2026-09-11。版本：1.0.0-alpha.3。

## 原因与修改

用户这次的语音被识别为“嗯，好的，你退下吧。”。后台日志显示 13:47:26 Qwen 回答“好的，再见！”但 response.done 没有工具调用；13:47:27.840 浏览器确认音频排空后，没有进入结束会话流程。这里没有额外 3 秒退出计时，是语音模型漏调用 end_conversation。

现在提示词明确要求告别必须调用结束工具；同时对整句明确退出指令增加本地补充处理，绑定当前话轮和告别 speechId。模型只生成声音而未调用工具时，复用这条声音，实际排空后退出。转写晚于声音结束时直接退出，不重复生成第二句告别。无需额外模型请求或 TTS。

补充规则只识别完整明确的退出命令；单纯道谢、否定、引用、提问和带后续任务的复杂句子仍交给模型处理。插话清除原退出意图；旧话轮转写、被取消响应和报告播报不能触发退出。演示模式使用同一规则。

## 验证

- 完整工作区和独立组件库类型检查、构建及 45 项行为测试通过；最后补强的插话后迟到转写场景通过 9 项相关回归。
- Edge 实际 AudioWorklet 加模型夹具：故意省略结束工具，仅说告别，仍只播一次并在排空后退出；等待 16 秒无超时错误。插话继续、点击关闭、模型同时输出声音与结束工具均通过。
- Edge 浏览器麦克风输入合成录音“嗯，好的，你退下吧。”，连接真实 Qwen。播放结束后 7 毫秒收到 session.idle，角色按钮恢复“唤醒小云”；随后 3.2 秒无重复退出。此耗时是该次浏览器事件观测，不是所有设备的延迟承诺。
- 本轮没有重跑分析、联网与全量跨浏览器用例，沿用 alpha.2 的对应记录；实体麦克风/扬声器听感需用户继续体验。

SDK 与后台同步更新到 alpha.3，刷新宿主页面。此次为新增私有预发行版本，不改写 alpha.2 标签。
