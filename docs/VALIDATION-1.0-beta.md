# 小云 1.0-beta：移除字幕区域多余留白

日期：2026-09-11。版本：1.0.0-beta.1。

删除“存在任何资料卡就保留 200px 字幕区域”的样式和触发属性，区域现在只按实际字幕、任务提示和新结果通知占高。资料卡与相邻内容保留 12px 间距，通知与字幕保持原有 10px 间距。没有替换成其他固定占位，也没有修改后台业务逻辑。

沿用现有阅读保护：阅读时不把新结果强行合入旧卡片列表、不自动滚到底部。此次移除占位后，相关播放/阅读回归仍通过。

验证：

- 修改前，新增的实际布局检查在旧版稳定失败：资料卡到新结果提示的空隙约 100.28px。
- Edge、Chrome 的实际 AudioWorklet 前端夹具通过。单行字幕、流式追加为两行天气文字、资料到通知的间距均为 12px；字幕退场后，空字幕区域高度为 0。
- 同时验证通知不遮挡字幕或资料、原有 10 秒退场、固定保留、当前语音文字归属、插话丢弃旧文字与边缘拖动。
- Edge 播放/阅读集成通过：正在读的旧卡位置从 27.28px 到 25.84px，未被新结果挤走，原有三张普通卡窗口和显式合入行为正常。
- 类型检查、构建和现有 46 项行为测试通过；截图检查确认短回复没有大片空白。

复测命令：`npx tsx scripts/verify-caption.ts msedge`、`npx tsx scripts/verify-caption.ts chrome`。天气文字只用作布局样例，不是本次联网天气查询。

本轮未调用真实模型或录制实体麦克风。SDK 与后台发行/协议版本同步为 1.0.0-beta.1，后台语音与任务源代码不变。

版本命名按用户确认改为 **1.0-beta**，安装包、协议和 Git 标签采用 **1.0.0-beta.1**。历史 alpha 验收记录保留原名。布局与播放回归先在未发布候选 alpha.6 上完成，最终 beta 构建再次验证协议和页面；原始证据保留运行时版本，不改写成其他版本。
