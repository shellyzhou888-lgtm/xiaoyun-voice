## Grok Bot character study

The character geometry, eye morphs, spring poses, overlays and particle engine in
`src/ui/vendor/grok-engine.ts` are adapted from the local copy of
[blessonism/grok-icon-study](https://github.com/blessonism/grok-icon-study).

The original project is a study of the Grok Bot.app v0.18.0 login character.
Its README states: “素材归 xAI / 相应权利人所有。本仓库仅供学习参考，请勿商用或再分发。”
Character designs, trademarks, icons, geometry and extracted application material
belong to xAI or their respective rights holders. These materials are not claimed
as original Xiaoyun artwork. The study repository has not been modified.

Local adaptations: module-scoped exports; task-driven states and continuous rest motion;
actual animation suspension; disabled random tricks; shortened waking transition;
curious/humming/dictating/happy pose mapping; reduced-strength native hover bounce;
speech amplitude driven waveform with a retained face and transitions without half-turns.
This integration is intended for the user's
specified internal learning/evaluation use. Preserve this notice with local copies.
